# quickmart-frontend

QuickMart e-commerce frontend - single-page application for Buyer and Seller experiences.

## Features

- Buyer: product catalog, search, product detail, shopping cart, checkout with test payment, order history
- Seller: login, product management (CRUD), view orders

## Tech Stack

- React (or Angular)
- TypeScript
- Vite / Angular CLI
- Bootstrap / CSS

## Delivery

Built by Jenkins CI, uploaded to Amazon S3, and served via Amazon CloudFront at `quickmart.pinakaone.in`.

## Local Development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```
